Remarks

This interface is used only as the receiver type of an expression tree captured by linq2db. The configure expression is parsed by linq2db and is not invoked; implementing this interface is not a supported extension point.

Match(Expression<Func<TTarget, TTarget, bool>>)

Defines the key-equality used to match source rows to target rows: a conjunction of equality comparisons between target and source member paths — e.g. (t, s) => t.Id == s.Id or (t, s) => t.TenantId == s.TenantId && t.ExternalId == s.ExternalId. This is not a general boolean predicate; use the branch .When(...) predicates for conditional INSERT/UPDATE logic. When omitted, the target table's primary key is used (same as today's InsertOrUpdate). Columns referenced by the match identify the row and are excluded from the UPDATE branch's SET list.
